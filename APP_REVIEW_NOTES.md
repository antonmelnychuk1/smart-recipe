# App Review Notes

Copy this into App Store Connect when submitting the first iOS build.

## Notes

SmartRecipe is a web-based iOS app built with Capacitor. The app loads:

```text
https://smartrecipeapp.com
```

The app helps users generate recipe ideas from pantry ingredients or from a dish name. Users can save recipes, manage a shopping list, manage pantry items, plan meals and update cooking preferences.

The app does not request camera, microphone, location, contacts or photo library access in the current version.

AI-generated recipes, nutrition values and costs are estimates. Users should review allergens, ingredient freshness and safe food preparation practices.

## Demo account

Create this account manually before submission and paste the temporary password only into App Store Connect review notes.

```text
Email: reviewer@smartrecipeapp.com
Password: [create temporary password before submission]
```

Please do not commit the reviewer password to the repository.

## Suggested review flow

1. Open the app.
2. Log in with the demo account.
3. Add ingredients such as eggs, rice and chicken.
4. Generate recipes.
5. Open a recipe.
6. Add a missing ingredient to the shopping list.
7. Save a recipe.
8. Open the meal planner.
9. Open the kitchen/pantry tab.
10. Open account settings.
