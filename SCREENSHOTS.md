# App Store Screenshot Plan

Use this file as the shot list for the first SmartRecipe iOS submission.

## Recommended iPhone screenshots

Apple usually asks for screenshots in App Store Connect for current large iPhone displays. The safest first set is 6.9-inch screenshots from the latest iPhone Pro Max simulator.

Prepare 6 screenshots:

1. Home generator
   - Caption: `Cook with what you already have`
   - Show the main ingredient generator with a few ingredients added.

2. Generated recipes
   - Caption: `Get recipe ideas in seconds`
   - Show compact recipe cards with real food photos.

3. Recipe details
   - Caption: `Ingredients, steps and nutrition`
   - Show quantities, missing ingredients and substitutions.

4. Cooking mode
   - Caption: `Follow every step while cooking`
   - Show step navigation and checklist/timer if visible.

5. Meal planner
   - Caption: `Plan meals for the week`
   - Show a week with a few planned meals.

6. Kitchen / pantry
   - Caption: `Keep your kitchen organized`
   - Show pantry items, shopping list or expiry tracking.

## Optional screenshots

Add these later if the first listing needs more explanation:

- Saved recipes
- Recipe history
- Cooking preferences
- Language/currency/region switch
- Admin panel is not recommended for public screenshots

## Screenshot style

- Use real app screens, not mockups, for the first submission.
- Keep the same language across all screenshots.
- Recommended first language: English.
- Avoid showing private email addresses, real names or admin data.
- Use pleasant sample ingredients and recipes.
- Make sure bottom iOS tab bar is visible and not covering content.

## Before taking screenshots

- Use production domain: `https://smartrecipeapp.com`.
- Delete old app from Simulator.
- Run the newest iOS build.
- Create or use a clean demo account.
- Set language to English.
- Set currency/price region to the global/default option you want to present.
- Generate fresh example recipes.
- Save at least one recipe.
- Add a few pantry and shopping list items.
- Add a few meal plan entries.
